## Implementation Details
The endpoint is implemented in `src/server.js` (lines 177-244) with:
- GET endpoint: `/api/preview/headers?url=...`

## Supporting Functions
- `buildHeadersPreviewResult()`: Main result builder
- `categorizeHeaders()`: Groups headers by type
- `assessSecurityHeaders()`: Security scoring
- `analyzeCorsHeaders()`: CORS configuration analysis
- `analyzeServerHeaders()`: Server disclosure analysis
- `assessPerformanceHeaders()`: Performance scoring

## Dependencies
- `./header-analyzer.js`: `analyzeResponseHeaders()` for detailed analysis
- `./fetcher.js`: `fetchUrl()` and `parseMetaTags()` for HTML fetching
