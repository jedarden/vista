## Overall Code Organization Pattern

- **Monolithic single-file application** - All client-side logic in one file
- **Imperative DOM manipulation** - Direct DOM queries and updates
- **Event-driven architecture** - Extensive event listeners and callbacks
- **State-based rendering** - `currentData` drives most UI updates

### Code Organization Characteristics

1. **Section-based organization** - Clear sections marked with `// ── Section Name ──` headers
2. **Global state management** - Heavy reliance on global variables
3. **DOM reference caching** - Extensive upfront DOM element caching
4. **Function definition pattern** - Mix of `function`, `async function`, and arrow functions
5. **Hook-style extension** - Function replacement for cross-cutting concerns

### Hook Usage Patterns

The codebase uses a **function replacement hook pattern** for cross-cutting concerns:

**Pattern:**
```javascript
const originalFunctionName = functionName;
functionName = function(...args) {
  // Pre-processing
  const result = originalFunctionName(...args);
  // Post-processing
  return result;
};
```

**Examples Found:**
1. **renderDiagnostics hook** - Adds diagnostic tracking after rendering
2. **handleResult hook** - Injects smart ordering before rendering

**Purpose:** Enable features (smart ordering, diagnostic tracking) without modifying core functions

### Guard Flag Pattern

Extensive use of **guard flags** to prevent race conditions:

**Key Flags:**
- `isApplyingSmartOrder` - Prevents concurrent smart ordering operations
- `isSmartOrderingActive` - Runtime state tracking
- `isFilterOperation` - Prevents smart order resets during filtering
- `pendingRenderData` - Queued render operations
- `pendingFilterOperations` - Queued filter operations
- `pendingApplySmartOrder` - Queued smart ordering

**Pattern: Thread-safe operations with queuing**
```javascript
function applySmartOrderingSafe() {
  if (isApplyingSmartOrder) {
    pendingApplySmartOrder = true;
    return;
  }
  isApplyingSmartOrder = true;
  try {
    // Do work
  } finally {
    isApplyingSmartOrder = false;
    // Process pending operations
  }
}
```
