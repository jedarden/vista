## Implementation Architecture

### State Management
```javascript
let cardContextState = {};
// Per-card: cardContextState[pid] = { context: false, theme: 'dark' }
```

### Theme Toggle Flow
1. User clicks theme toggle button → triggers click event listener
2. Event listener calls `toggleCardTheme(pid, data)`
3. Function validates state and data, then toggles theme
4. If in context mode, re-renders card body with new theme
5. Calls `updateCardHeader(pid)` to refresh button icon
6. Console logs theme transition for debugging

### Platform Support
- Twitter/X is included in `PLATFORMS_WITH_THEME` array
- Button only renders for supported platforms
- Falls back to empty array if platform config module fails to load

### CSS Integration
- Dark theme: `.twitter-context` with default dark CSS variables
- Light theme: `.twitter-context.light-theme` with light theme overrides
- Theme variables: `--frame-bg`, `--frame-surface`, `--frame-border`, `--frame-text-primary`, etc.
