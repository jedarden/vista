## Response Structure

```javascript
{
  url: string,
  finalUrl: string,
  statusCode: number,
  images: {
    og: ImageData | null,
    twitter: ImageData | null,
    favicon: ImageData | null,
    hero: ImageData[],
    all: ImageData[]
  },
  recommendations: Recommendation[],
  redirectChain: RedirectHop[]
}
```

## ImageData Structure

```javascript
{
  url: string,
  width: number | null,
  height: number | null,
  contentType: string | null,
  contentLength: number | null,
  responseTime: number,
  cors: string | null,
  statusCode: number,
  cropRatios: {
    aspectRatio: number,
    landscape: { ratio, recommended, actual, willCrop },
    square: { ratio, recommended, actual, willCrop },
    portrait: { ratio, recommended, actual, willCrop }
  }
}
```

## Implementation Notes

- Slower operation (~1-3s) as designed - blocks on image dimension probing
- Uses `probe-image-size` library for dimension detection
- Probes all images in parallel with `Promise.allSettled`
- Categorizes images by type (og, twitter, favicon, hero)
- Generates platform-specific recommendations based on dimensions
- Handles errors gracefully - failed probes return null dimensions
