## 🐛 Troubleshooting

### Server won't start
- Check if port 8081 is already in use: `lsof -i :8081`
- Kill existing process: `pkill -f serve-dark-theme-pages.js`
- Try a different port by editing the PORT variable in the server script

### HTML page loads but frame is empty
- Check browser console for errors (F12)
- Verify platform-frames.js and app.js are accessible
- Ensure the file paths in the HTML are correct

### Screenshot file won't save
- Check directory permissions: `ls -la screenshots/dark-theme/`
- Ensure write permissions: `chmod u+w screenshots/dark-theme/`
- Verify disk space: `df -h`

### Verification fails
- Check that all filenames match exactly (case-sensitive)
- Ensure files are in the correct directory
- Verify files are not corrupted: `file *.png`
