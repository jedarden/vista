## ✅ READY FOR MANUAL CAPTURE

All infrastructure is complete and ready. To complete this task:

### Step 1: Transfer Files (if needed)
If working in a different environment, copy the `screenshots/dark-theme/` directory.

### Step 2: Start Server
```bash
cd screenshots/dark-theme
node serve-dark-theme-pages.js
```

### Step 3: Open Browser & Capture
1. Navigate to `http://localhost:8081/`
2. Click each platform link
3. Capture screenshot of the platform frame
4. Save as `platform-name-dark.png`

### Step 4: Verify
```bash
node verify-dark-theme-screenshots.js
```

### Step 5: Commit & Complete
```bash
git add screenshots/dark-theme/*-dark.png
git commit -m "feat(bf-b6pnm): add dark theme platform screenshots"
```
