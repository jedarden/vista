## 🚀 Quick Start Guide

### 1. Start the Screenshot Server
```bash
cd screenshots/dark-theme
node serve-dark-theme-pages.js
```

### 2. Open in Your Browser
Navigate to: http://localhost:8081/

You'll see a gallery with all 7 platforms.

### 3. Capture Screenshots
For each platform:
1. Click the platform name (e.g., "X (Twitter)")
2. When the page loads, take a screenshot of the platform frame (the dark box in the center)
3. Save as `platform-name-dark.png`:
   - `twitter-dark.png`
   - `discord-dark.png`
   - `instagram-dark.png`
   - `telegram-dark.png`
   - `signal-dark.png`
   - `whatsapp-dark.png`
   - `mastodon-dark.png`

### 4. Verify
```bash
node verify-dark-theme-screenshots.js
```

### 5. Commit and Complete
```bash
git add screenshots/dark-theme/*-dark.png
git commit -m "feat(bf-b6pnm): add dark theme platform screenshots"
git push
br close bf-b6pnm
```
