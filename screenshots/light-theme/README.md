## 🚀 Quick Start Guide

### 1. Start the Screenshot Server
```bash
node manual-screenshot-server.js
```

### 2. Open in Your Browser
Navigate to: http://localhost:8080

You'll see a gallery with all 7 platforms.

### 3. Capture Screenshots
For each platform:
1. Click the platform name (e.g., "X (Twitter)")
2. When the page loads, take a screenshot of the platform frame (the white box in the center)
3. Save as `platform-name-light.png`:
   - `twitter-light.png`
   - `discord-light.png`
   - `instagram-light.png`
   - `telegram-light.png`
   - `signal-light.png`
   - `whatsapp-light.png`
   - `mastodon-light.png`

### 4. Verify
```bash
node verify-screenshots.js
```

### 5. Commit and Complete
```bash
git add screenshots/light-theme/*-light.png
git commit -m "feat(bf-4ubla): add light theme platform screenshots"
git push
br close bf-4ubla
```
