🧪 VISTA smartOrdering Manual Test

Manual UI testing checklist for smartOrdering functionality

0%

Test 1: Initial Page Load with smartOrdering

Steps:
  1. Click the link below to open VISTA with smartOrdering=true
  2. Verify the page loads without errors
  3. Check the browser console (F12 → Console) for any errors
  4. Confirm platform cards are rendered

Test 2: URL Input and Analysis

Steps:
  1. In the VISTA page, type "https://github.com" in the URL input field
  2. Click the "Inspect" or "Analyze" button
  3. Verify the results load without errors
  4. Check that platform cards show preview data

Test 3: Platform Card Interactions

Steps:
  1. Hover over a platform card
  2. Click the favorite button (heart icon) on any platform card
  3. Verify visual feedback (button state changes)
  4. Check browser console for errors

Test 4: Verify smartOrdering is Active

Steps:
  1. Open browser console (F12 → Console)
  2. Type: window.platformPrefs.smartOrdering
  3. Verify it returns true
  4. Or check URL: new URLSearchParams(location.search).get('smartOrdering')

Test 5: Column Count Selector

Steps:
  1. Find the column count selector (usually 1, 2, 3, 4 buttons)
  2. Click different column counts
  3. Verify platform cards rearrange accordingly
  4. Check for any layout issues

Test 6: Theme Toggle

Steps:
  1. Click the theme toggle button (☀️/🌙) in the header
  2. Verify the theme changes from dark to light or vice versa
  3. Check that platform cards remain readable
  4. Verify no console errors occur
