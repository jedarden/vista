✅ Dark Mode Verification Checklist

  • Facebook: Background #242526, primary text #e4e6eb, secondary text #b0b3b8, accent #2d88ff
  • Twitter/X: Background #000000, primary text #e7e9ea, secondary text #71767b, accent #1d9bf0
  • LinkedIn: Background #000000, primary text #ffffff, secondary text #a8b3ba, accent #0a66c2
  • Reddit: Background #1a1a1e, primary text #e4e4e7, secondary text #a5a5a9, accent #FF4500
  • Instagram: Background #000000, primary text #ffffff, secondary text #a8a8a8, accent #e1306c
  • YouTube: Background #0f0f0f, primary text #ffffff, secondary text #aaaaaa, accent #ff0000
  • TikTok: Background #000000, primary text #ffffff, secondary text #a8a8a8, accent #ff0050

🎨 Expected Dark Mode Behaviors

  • All platforms: Dark backgrounds (#000000, #1a1a1e, #242526, etc.)
  • Text contrast: Light text colors for primary and secondary text
  • Borders: Reduced contrast borders (#262626, #2f3336, #343536, etc.)
  • CSS Variables: All frames use --frame-* CSS custom properties for theming
  • Brand colors: Platform accent colors preserved (Facebook blue, Reddit orange, etc.)
  • Visual consistency: Platform identity preserved in dark mode
  • Surface colors: Dark gray surfaces (#1a1a1b, #121212, #23262a, etc.) for cards/containers
  • Overlay: Dark overlays (rgba(0,0,0,0.6-0.7)) for modal/shadow effects

🔍 CSS Variables Applied (Dark Mode)

  • --frame-bg: Background color of the frame (dark)
  • --frame-surface: Card/container background (dark gray)
  • --frame-border: Border color (reduced contrast gray)
  • --frame-text-primary: Main text color (light)
  • --frame-text-secondary: Secondary text color (medium gray)
  • --frame-text-muted: Muted/disabled text (lighter gray)
  • --frame-accent: Brand accent color (platform-specific)
  • --frame-accent-bg: Accent background (platform-specific)
  • --frame-link-color: Link text color (platform-specific)
  • --frame-divider: Divider line color (medium gray)
  • --frame-input-bg: Input background (dark gray)
  • --frame-overlay: Overlay/shadow (rgba(0,0,0,0.6-0.7))

🧪 Theme Toggle Functionality Test

  • Test: Click the theme toggle button in the top-right corner
  • Expected: All 7 frames should switch from dark to light mode simultaneously
  • Expected: CSS variables should update for all platforms
  • Expected: Smooth transitions (0.3s ease) on all themeable elements
  • Expected: Platform brand colors preserved in both modes
  • Expected: Frame labels should update to reflect current theme
  • Expected: Button text should change from "☀️ Light Mode" to "🌙 Dark Mode"
