✅ Light Mode Verification Checklist

  • Facebook: Background #ffffff, primary text #050505, secondary text #65676b, accent #1877f2
  • LinkedIn: Background #ffffff, primary text #000000, secondary text #666666, accent #0a66c2
  • Reddit: Background #ffffff, primary text #1c1c1c, secondary text #5a5a5a, accent #FF4500
  • Instagram: Background #ffffff, primary text #000000, secondary text #737373, accent #e1306c
  • YouTube: Background #ffffff, primary text #0f0f0f, secondary text #606060, accent #ff0000
  • TikTok: Background #ffffff, primary text #1a1a1a, secondary text #666666, accent #e60045
  • Pinterest: Background #ffffff, primary text #111111, secondary text #767676, accent #E60023

🎨 Expected Light Mode Behaviors

  • All platforms: Light/white backgrounds (#ffffff or similar)
  • Text contrast: Dark text colors for primary and secondary text
  • Borders: Standard contrast borders (#e5e5e5, #ccc, etc.)
  • CSS Variables: All frames use --frame-* CSS custom properties for theming
  • Brand colors: Platform accent colors preserved (Facebook blue, Reddit orange, etc.)
  • Visual consistency: Platform identity preserved in light mode
  • Surface colors: Light gray surfaces (#f0f2f5, #f9f9f9, etc.) for cards/containers
  • Overlay: Light overlays (rgba(0,0,0,0.1)) for modal/shadow effects

🔍 CSS Variables Applied (Light Mode)

  • --frame-bg: Background color of the frame (white/light)
  • --frame-surface: Card/container background (light gray)
  • --frame-border: Border color (medium gray)
  • --frame-text-primary: Main text color (dark)
  • --frame-text-secondary: Secondary text color (medium gray)
  • --frame-text-muted: Muted/disabled text (lighter gray)
  • --frame-accent: Brand accent color (platform-specific)
  • --frame-accent-bg: Accent background (platform-specific)
  • --frame-link-color: Link text color (platform-specific)
  • --frame-divider: Divider line color (medium gray)
  • --frame-input-bg: Input background (white/light gray)
  • --frame-overlay: Overlay/shadow (rgba(0,0,0,0.1))
