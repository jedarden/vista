Capture screenshots of YouTube and TikTok frames in both themes

▶️ YouTube

YouTube Chrome Elements:

  • Video player with play button overlay
  • Channel avatar with proper sizing
  • Channel name and subscriber count
  • Subscribe button (red/YouTube styled)
  • Action buttons (Like, Share, Save)
  • Video title and description

🎵 TikTok

TikTok Chrome Elements:

  • Video container with proper aspect ratio
  • Right sidebar with action icons

📋 Screenshot Instructions

  1. Take a screenshot in DARK mode (current view)
  2. Click the "🌓 Toggle Theme" button at top-right
  3. Wait for the theme transition to complete
  4. Take a screenshot in LIGHT mode
  5. Save screenshots with descriptive names:
    youtube-frame-dark.png
    youtube-frame-light.png
    tiktok-frame-dark.png
    tiktok-frame-light.png
  6. Verify each screenshot shows realistic platform chrome
  7. Check for proper theme colors, contrast, and readability
