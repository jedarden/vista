How to implement async/await error handling in JavaScript?

I'm trying to properly handle errors when using async/await in JavaScript. What's the best practice for catching and handling errors in async functions?

// Example code that needs error handling async function fetchUserData(userId) { const response = await fetch(`/api/users/${userId}`); const data = await response.json(); return data; }

The best practice is to use try/catch blocks with async/await. Here's a comprehensive example:

async function fetchUserData(userId) { try { const response = await fetch(`/api/users/${userId}`); if (!response.ok) { throw new Error(`HTTP error! status: ${response.status}`); } const data = await response.json(); return data; } catch (error) { console.error('Failed to fetch user:', error); throw error; // Re-throw for caller to handle } }

You can also use the pattern of wrapping async calls in helper functions:

// Helper function for error handling const to = (promise) => promise .then(data => [null, data]) .catch(err => [err, null]); // Usage const [error, user] = await to(fetchUserData(123)); if (error) { // handle error }

// Global error handler process.on('unhandledRejection', (reason, promise) => { console.error('Unhandled Rejection at:', promise, 'reason:', reason); // Application specific logging, throwing in an error, or other logic here });

You can also use .catch() with async/await:

const user = await fetchUserData(123) .catch(error => { console.error('Error fetching user:', error); return null; // Return fallback value });
