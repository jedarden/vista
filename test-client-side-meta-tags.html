Test Page: Client-Side Meta Tags

This page intentionally injects all meta tags via JavaScript to test VISTA's client-side-only tag detection.

Expected Behavior:

  • VISTA should detect that og:image, og:title, og:description are injected via JavaScript
  • VISTA should show an error diagnostic with code 'js-injected-tags'
  • VISTA should show severity 'error'
  • The diagnostic message should be actionable (suggest SSR/prerendering)
