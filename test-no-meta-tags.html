Test No Meta Tags Detection

This page tests the feature that detects pages with no meta tags and suggests opening the template picker.

Test 1: Page with no meta tags at all

A basic HTML page with only title, no Open Graph or Twitter Card tags.

<!DOCTYPE html> <html> <head> <title>Test Page</title> </head> <body> <h1>Hello</h1> </body> </html>

Test 2: Page with only empty meta tags

A page with OG/Twitter meta tags present but with empty values (should NOT show suggestion).

<!DOCTYPE html> <html> <head> <meta property="og:title" content=""> <meta property="og:description" content=""> <meta name="twitter:card" content=""> <title>Test Page</title> </head> <body> <h1>Hello</h1> </body> </html>

Test 3: Page with partial meta tags (og:title only)

A page with only one OG tag (should NOT show suggestion).

<!DOCTYPE html> <html> <head> <meta property="og:title" content="My Page"> <title>Test Page</title> </head> <body> <h1>Hello</h1> </body> </html>

Test 4: Page with full meta tags

A complete page with all OG and Twitter tags (should NOT show suggestion).

<!DOCTYPE html> <html> <head> <meta property="og:title" content="My Page"> <meta property="og:description" content="A description"> <meta property="og:image" content="https://example.com/image.jpg"> <meta name="twitter:card" content="summary_large_image"> <meta name="twitter:title" content="My Page"> <meta name="twitter:description" content="A description"> <meta name="twitter:image" content="https://example.com/image.jpg"> <title>Test Page</title> </head> <body> <h1>Hello</h1> </body> </html>
