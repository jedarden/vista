Theme Chrome Verification Checklist

  • ✓ TikTok frame uses CSS variables from frames-theme.css for all colors
  • ✓ TikTok frame chrome (header, footer, borders) adapts to dark and light themes
  • ✓ Background colors, borders, and text colors use theme variables
  • ✓ Visual contrast is maintained in both dark and light themes
  • ✓ The tiktok-context class properly applies theme colors
  • ✓ Both theme modes render with correct chrome styling
  • ✓ Frame chrome elements use --frame-bg, --frame-surface, --frame-border
  • ✓ Text colors use --frame-text-primary, --frame-text-secondary, --frame-text-muted
  • ✓ Accent colors use --frame-accent and --frame-accent2
  • ✓ Overlay effects use --frame-overlay
  • ✓ Hover states use --tiktok-hover-bg
  • ✓ Transitions use --frame-transition-global
